3. Calcul du statut dynamique
Avant 1ère délivrance
→ patients.status = 'en_attente'
→ aucune ligne dans suivi_therapeutique

Après 1ère délivrance
→ ecart = CURRENT_DATE - date_prochaine_prise

ecart ≤ 2 jours          → actif
2 < ecart ≤ 179 jours    → en_retard
ecart ≥ 180 jours        → perdu_de_vue

était perdu_de_vue
+ nouvelle délivrance    → recupere (suivi_therapeutique)
                         → actif    (patients.status)

4. Règle 48h prescription
Patient vient APRÈS 48h
        ↓
Pharmacien ne trouve pas la prescription
        ↓
prescription.statut = 'non_validee'
        ↓
Patient retourne au médecin
        ↓
Médecin crée nouvelle prescription
        ↓
patients.status reste inchangé jusqu'à nouvelle délivrance


6. Règle de recalcul système
Système recalcule TOUJOURS à chaque délivrance
              ↓
    ┌─────────────────────────────────┐
    │ patients.status = administratif │
    │ + délivrance récente existe     │
    └─────────────────────────────────┘
              ↓
    ⚠️ ALERTE médecin
    "incohérence détectée — faute de frappe probable"
              ↓
    médecin décide :
    ✅ signale erreur  → système recalcule → bon statut auto
    ✅ confirme statut → délivrance = erreur à investiguer

    ┌─────────────────────────────────┐
    │ patients.status = administratif │
    │ + PAS de délivrance récente     │
    └─────────────────────────────────┘
              ↓
    ✅ garde le status administratif tel quel
    ✅ pas de recalcul

Exclure :
❌ en_attente
❌ decede
❌ decede_sida

❌ perdu_de_vue

8. Flux complet système
1. Patient créé
   → patients.status = 'en_attente'

2. Médecin crée prescription
   → prescription.statut = 'envoyee'
   → patients.status reste 'en_attente'

3. Pharmacien valide
   → prescription.statut = 'delivree'
   → date_delivrance = TODAY

4. Système calcule
   → ecart = CURRENT_DATE - date_prochaine_prise
   → détermine statut calculé
   → écrit suivi_therapeutique      (historique immuable)
   → écrit patients.status          (toujours)
   → ALERTE si contradiction        (administratif + délivrance)

5. Médecin si besoin
   → change vers administratif uniquement
   → signale faute de frappe → système recalcule

Durée = combien de temps la notif reste visible dans la barre.

7j :
notif créée aujourd'hui
→ reste visible 7 jours
→ au 8ème jour → disparaît automatiquement
→ même si médecin ne la lit pas
24h après clic :
notif avec lien
→ médecin clique le lien
→ timestamp du clic stocké en BD
→ 24h après → disparaît automatiquement
→ si médecin ne clique pas → reste jusqu'à 7j

Donc pour chaque notif avec lien :
disparaît si :
created_at > 7j    → expirée naturellement
OU
clicked_at + 24h   → médecin a agi
Pour chaque notif sans lien :
disparaît si :
created_at > 7j    → expirée naturellement
