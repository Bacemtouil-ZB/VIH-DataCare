# VIH-DataCare-app

Plateforme web pour la gestion des patients VIH avec modules front-end, back-end et service IA prédictif.

## Structure du projet

- `frontend/` : interface utilisateur (Vite + JS ou React)  
- `backend/` : serveur et API (Node.js / Express ou autre)  
- `ml-service/` : service IA Python pour prédiction (optionnel)  
- `docs/` : documentation projet et guides .

## Utilise Tailwind pour

- pages publiques
landing page
auth (login / signup)

## Utilise Bootstrap pour

dashboard
admin
formulaires complexes
