| Category             | Package                                     | Role                     | Usage in Your App                                       |
| -------------------- | ------------------------------------------- | ------------------------ | ------------------------------------------------------- |
| **Navigation**       | `@react-navigation/native`                  | Core navigation system   | Manages navigation state across the app                 |
|                      | `@react-navigation/stack`                   | Stack navigation         | Login → Home → Details flow                             |
|                      | `@react-navigation/bottom-tabs`             | Tab navigation           | Main sections (Home, Rendez-vous, Profile, Reminders)   |
|                      | `react-native-screens`                      | Performance optimization | Improves navigation performance using native components |
|                      | `react-native-safe-area-context`            | Safe UI layout           | Prevents UI overlap with notch/status bar               |
| **API / Networking** | `axios`                                     | HTTP client              | Calls backend API (login, rendez-vous, reminders)       |
| **State Management** | `zustand`                                   | Global state manager     | Stores auth (token, user) and shared data               |
| **Forms**            | `react-hook-form`                           | Form handling            | Manages inputs (login, profile, reminders)              |
|                      | `zod`                                       | Data validation          | Validates form data (email, password, etc.)             |
|                      | `@hookform/resolvers`                       | Integration tool         | Connects react-hook-form with zod                       |
| **Storage**          | `@react-native-async-storage/async-storage` | Local storage            | Stores non-sensitive data (settings, cache)             |
|                      | `expo-secure-store`                         | Secure storage           | Stores JWT token and sensitive data (VERY IMPORTANT)    |
| **Mobile Features**  | `expo-notifications`                        | Notifications system     | Medication reminders, appointment alerts                |
|                      | `expo-device`                               | Device info              | Detect device type, debugging, analytics                |
